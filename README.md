# Bookstore GUI Application

## Overview
A **Bookstore Management System** built with **Java Swing** and **Apache Derby (Embedded)**.  
It follows an **MVC architecture**, demonstrating **Object-Oriented Design**, **database integration**, and a **clean, user-friendly GUI**.

---

## Features

### User Login / Profile
- Sign In using **name + password**
- Secure registration with **salted password hashing**
- Update display name and view profile
- Logout → safely returns to login screen (restart behavior)

### Book Management
- View all books with **cover images**
- **Search** books by title or author (partial match supported)
- Displays “No results” message if nothing matches
- Auto-refresh when clearing the search field

### Shopping Cart
- Add or remove books, merge duplicate items
- Validate available stock automatically
- Compute subtotals and total price dynamically
- Proceed to **Checkout** to generate an order

### Orders
- View all past orders for the signed-in user
- Cancel pending orders
- View receipts showing items, quantities, and total amount

---

## 🗄️ Database Integration

**Apache Derby Embedded (auto-created on launch)**  
- No external setup or manual configuration required.  
- Schema auto-generated by `DbManager` on startup.

Tables:
- `Users` – authentication and profiles  
- `BookProducts` – catalog and stock tracking  
- `Orders` – user purchase records  
- `OrderItems` – book list per order  

📊 **I/O Coverage:**
- `DbUserRepository` → Register, Authenticate, Update name  
- `DbBookRepository` → FindAll, FindByTitleLike, UpdateStock  
- `DbOrderRepository` → Create, Cancel, FindByUser  
(Each performs **3+ Reads / 3+ Writes**)

## 🧩 Software Design

### Object-Oriented Programming
- **Encapsulation:** Private fields with getters/setters (User, BookProduct, Order)  
- **Abstraction:** Repository interfaces define high-level operations  
- **Polymorphism:** Multiple DB implementations follow same interface contract  
- **Inheritance:** Future-ready extension via abstract `DiscountPolicy` (for checkout logic)

### Design Patterns
- **Repository Pattern** – separates data access (DbUserRepository, DbBookRepository, DbOrderRepository)  
- **Singleton Pattern** – centralized DB connection via `DbManager`  
- **Strategy Pattern** – designed for optional discount logic at checkout  

### Architecture
- **Model** → domain classes (`BookProduct`, `Order`, `User`)  
- **View** → Swing components (`MainFrameForm`, `BooksView`, `CartView`, `OrdersView`)  
- **Controller** → `CartController`, `UserContext`  

---

## GUI Design
- Developed using **NetBeans GUI Builder (Swing)**  
- Organized layout using `JSplitPane` (sidebar + main content) and `CardLayout` for page switching  
- Sidebar includes:  
  - **Profile**, **Logout**, **Search**, **Books**, **Cart**, **Orders**  
- Responsive and intuitive — users can navigate freely or log out anytime  
- All invalid inputs handled gracefully with dialog or message feedback
